سكوب كوفي — ابدأ من هنا

هذه الحزمة تحتوي المشروع الكامل بنفس التصميم والخطوط والخيارات السابقة.

1. فك الضغط، وارفع محتويات مجلد scoop-cafe إلى جذر مستودع GitHub. يجب أن يظهر package.json بجانب الملفات الأربعة الأصلية، مع المجلدات الجديدة.
2. في Supabase > SQL Editor شغّل الملف SUPABASE_SETUP.sql كاملًا مرة واحدة.
3. في Vercel اختر Framework Preset = Next.js، واترك Output Directory على الافتراضي.
4. أضف SUPABASE_URL وSUPABASE_SERVICE_ROLE_KEY وSTAFF_ADMIN_BOOTSTRAP إلى Environment Variables.
5. لإنشاء قيمة حساب المدير: شغّل npm run create-admin على حاسبتك داخل مجلد المشروع؛ سيطلب كلمة مرور تختارها وينتج JSON للمتغير الثالث.
6. نفّذ Redeploy بعد حفظ المتغيرات.
7. افتح رابط Production الذي يعطيك Vercel. واجهة الزبون في / والكاشير في /admin.

لا تضع مفتاح service_role داخل ملف supabaseClient.js أو أي ملف مرفوع إلى GitHub.

شرح مفصل وأوامر الاستيراد والاختبار في README_AR.md.
